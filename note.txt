 == Github simple syntax ==
    • git add file_name             - stage a file (ex: git add main.js)
    • git add .                     - stage everything changed at once
    • git commit -m "message"       - save staged changes with a description (ex: git commit -m "fix qty stepper going below 0")
    • git push                      — upload commits to GitHub

    • git push -u origin main       - use this ONLY ONCE the very first time this repo is ever pushed to Github
    • git status                    - check whats changed/staged/not committed
    • git log                       - see commit history
    • git branch                    - see which branch youre on

    Step by Step of git in someone's repository:
      1. git clone [repo link] - first you must clone the repo you want to contribute with if this is your first time.
      2. you must be inside of the actual folder of the project.
      3. git switch -c [branch name] - this is for making a branch in the repo for your own designated features.
      4. git status - you can use this to check the changes in the folder structure and to also check the branch you're in.
      5. git add . or [file(s) name] - staging files for commit.
      6. git commit -m "[description]" - save stage in the local device and ready for pushing.
      7. git push -u origin [branch name you're in] - this is the crucial part for pushing in someone's repo to out main github.
      8. git switch main or [another branch] - for switching either to main or preffered branch.

    -- Letter Suffix --
    • U = untracked/new (Git has never seen it)
    • A = added (staged)
    • M = modified
    • D = deleted

== PROJECT SETUP & INSTALLATION GUIDE (FOR TEAM MEMBERS) TO MAKE THE PROJECT RUN IN YOUR LOCAL MACHINE ==
   STEP 1: INSTALL PREREQUISITES
      Before running any terminal commands, ensure you have installed:
      1. Node.js (Download the LTS version from https://nodejs.org/dist/v26.13.0/node-v26.13.0-x64.msi) you must check the auto download components inside of installation. This also installs `npm`.
      2. Git (Download from https://github.com/git-for-windows/git/releases/download/v2.56.0.windows.4/Git-2.56.0.4-64-bit.exe)
      3. Run in terminal to download 'winget install Python.Python.3.12' in your terminal.
      4. Run in terminal to download 'winget install Microsoft.VisualStudio.2022.BuildTools --force --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --add Microsoft.VisualStudio.Component.VC.Tools.x86.x64 --add Microsoft.VisualStudio.Component.Windows10SDK.19041"'.

      To verify if they are installed, run these commands in your terminal:
      - node -v
      - npm -v
      - git --version
   
   STEP 2: CLONE THE REPOSITORY IF YOU STILL HAVEN'T
      Open your terminal, navigate to where you want the folder to be, and run:
      - git clone <PASTE_YOUR_GITHUB_REPO_LINK_HERE>
      - cd "[Folder Name]"
   
   STEP 3: INSTALL REQUIRED PACKAGES
      This is the most important step. Run this command to download all backend dependencies (Express, better-sqlite3, etc.) listed in the package.json file:
      - npm install
   
   STEP 4: SET UP AND SEED THE DATABASE
      Because we ignored the database file in Git (to prevent conflicts), your local database is completely empty. You must generate the tables and insert the menu items.
      Run these scripts to populate your database:
      - node scripts/seed-menu.js
      - node scripts/import-descriptions.js

      EXTENSION YOU WILL NEED FOR VIEWING DATABASE:
      - 'SQlite Viewer' by Florian Klampfer
   
   STEP 5: START THE SERVER
      Now, start the Express backend server:
      - node server.js

      You should see this message in the terminal:
      "Server running at http://localhost:3000"
   
   STEP 6: OPEN THE WEBSITE
      You can use chrome or right click the file and find 'Open file in Integrated Browser'.
   
   (WARNING: DO NOT double-click index.html in your folder. The website WILL NOT WORK. You must access it through localhost:3000 so the frontend can communicate with the backend server).
